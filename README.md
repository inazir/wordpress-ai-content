## 🔹 TCW Content Plugin

TCW Content Plugin is a modular WordPress plugin designed to automate high-quality blog content creation and publishing at scale.

Built for content-driven websites, it enables structured topic management, AI-powered article generation, and seamless publishing workflows — all directly inside the WordPress dashboard without relying on external cron-based scripts.

---

## 🚀 Core Features

### 🗂️ Bulk Topic Management
- Add, edit, and manage topics in a structured table  
- Status tracking: `pending`, `published`  
- Category assignment per topic  

### 🤖 AI Content Generation
- Integrates with AI APIs (e.g. Claude)  
- Generates SEO-optimized long-form articles  
- Supports title preservation logic (prevents unwanted AI rewriting)  

### ⚙️ Automated Publishing Workflow
- One-click or scheduled publishing  
- Direct publishing to WordPress posts  
- Category-based organization  

### 📂 CSV Import / Export
- Upload bulk topics using structured CSV format  
- Compatible with autoblogger pipelines  

### 🧩 Extensible Architecture
- Designed for multi-client use  
- Supports future modules:
  - Affiliate link injection  
  - Multi-language publishing  
  - Social media automation  
  - Deals engine integration
